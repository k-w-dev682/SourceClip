Polityka prywatności — SourceClip

Ostatnia aktualizacja: 6 listopada 2026 r.

Jakie informacje przetwarza SourceClip?

Rozszerzenie pozwala użytkownikowi zapisywać fragmenty zaznaczonego tekstu ze stron internetowych oraz własne notatki. Po wybraniu polecenia zapisu zaznaczenia może przechować tekst, adres URL i tytuł strony oraz datę zapisu. Przechowuje też nazwy projektów, przypisania fragmentów do projektów, ustawienia języka i motywów.

Zapisane treści mogą zawierać dane osobowe lub inne wrażliwe informacje, jeżeli użytkownik sam zdecyduje się je zapisać.

SourceClip nie monitoruje historii przeglądania ani nie gromadzi listy odwiedzanych stron. Użytkownik może jednak dobrowolnie przyznać rozszerzeniu dostęp do wybranych witryn i włączyć na nich automatyczne podświetlanie. W takim przypadku SourceClip lokalnie odczytuje tekst strony, aby odnaleźć zapisane wcześniej fragmenty i je podświetlić. Nie zapisuje w ten sposób całej treści odwiedzanej strony.

Gdzie dane są przechowywane?

Dane są przechowywane lokalnie przy użyciu API chrome.storage.local w profilu przeglądarki Chrome. W obecnej wersji rozszerzenie nie przesyła zapisanych danych do serwerów twórcy ani do zewnętrznych usług i nie prowadzi analityki ani profilowania.

Tekst stron odczytywany w celu odnajdywania i podświetlania zapisanych fragmentów jest przetwarzany lokalnie przez rozszerzenie.

Eksport i import danych

Użytkownik może samodzielnie zapisać kopię danych w pliku JSON lub Markdown albo wczytać własny plik. Wyeksportowany plik pozostaje w miejscu wybranym przez użytkownika i może zawierać treść notatek, tytuły i adresy stron. Za dalsze udostępnianie takiego pliku odpowiada użytkownik.

Uprawnienia

  • storage: lokalne przechowywanie fragmentów, projektów, notatek i preferencji użytkownika.
  • contextMenus: zapisywanie zaznaczonego tekstu po wybraniu polecenia w menu kontekstowym.
  • sidePanel: wyświetlanie SourceClip w panelu bocznym Chrome.
  • scripting: uruchamianie lokalnych skryptów rozszerzenia na stronach w celu odnajdywania i podświetlania zapisanych fragmentów.
  • activeTab: tymczasowy dostęp do aktywnej karty, wykorzystywany przez funkcje wymagające interakcji z aktualnie otwartą stroną.
  • Opcjonalny dostęp do witryn HTTP/HTTPS: użytkownik może przyznać dostęp do wybranych witryn, aby korzystać z funkcji automatycznego podświetlania. Dostęp można w każdej chwili cofnąć.

Usuwanie danych

Użytkownik może usuwać pojedyncze fragmenty, projekty i wszystkie zapisane fragmenty z poziomu interfejsu rozszerzenia. Usunięcie danych z profilu Chrome lub odinstalowanie rozszerzenia może również spowodować utratę danych. Przed takimi operacjami warto zrobić eksport JSON.

Zmiany polityki

Jeżeli przyszłe wersje zmienią sposób przetwarzania danych, polityka zostanie odpowiednio zaktualizowana przed wprowadzeniem tych zmian.

SourceClip Privacy Policy

Last updated: November 6, 2026

Data processed

SourceClip allows users to save selected text from websites and their own notes. When a user invokes Save Selection, the extension may store the selected text, webpage URL and title, and the save date. It also stores project names, clip-to-project assignments, interface language, and theme settings.

Saved content may contain personal or other sensitive information if users choose to save such content themselves.

SourceClip does not monitor browsing history or compile a list of visited websites. However, users may voluntarily grant the extension access to selected websites and enable automatic highlighting on those sites. In that case, SourceClip locally reads the webpage text to find and highlight previously saved clips. It does not use this process to save the entire content of visited pages.

Local storage and data transfer

Data is stored locally in the user's Chrome profile using the chrome.storage.local API. The current version does not send saved data to the developer's servers or third-party services and does not include analytics or user profiling.

Webpage text read to find and highlight saved clips is processed locally by the extension.

Import and export

Users may export a backup as JSON or Markdown or import files of their own. Exported files remain in the location selected by the user and may contain note text, webpage titles, and source URLs. Users are responsible for any further sharing of these files.

Permissions

  • storage: locally stores clips, projects, notes, and user preferences.
  • contextMenus: allows users to save selected text through the browser context menu.
  • sidePanel: displays SourceClip in the Chrome side panel.
  • scripting: allows local extension scripts to run on webpages to find and highlight saved clips.
  • activeTab: provides temporary access to the active tab for features that require interaction with the currently open webpage.
  • Optional HTTP/HTTPS website access: users may grant access to selected websites to use automatic highlighting. This access can be revoked at any time.

Deleting data

Users can delete individual clips, projects, or all saved clips through the extension interface. Removing data from the Chrome profile or uninstalling the extension may also result in data loss. Users should create a JSON backup before taking such actions.

Policy updates

This policy will be updated before any future version materially changes how user data is handled.
