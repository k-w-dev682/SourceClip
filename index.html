Polityka prywatności — SourceClip

Ostatnia aktualizacja: 6 listopada 2026 r.

Jakie informacje przetwarza SourceClip?

Rozszerzenie pozwala użytkownikowi zapisywać fragmenty zaznaczonego tekstu ze stron internetowych oraz własne notatki. Po wybraniu polecenia zapisu zaznaczenia może przechować tekst, adres URL i tytuł strony oraz datę zapisu. Przechowuje też nazwy projektów, przypisania fragmentów do projektów, ustawienia języka i motywów.

Zapisane treści mogą zawierać dane osobowe lub inne wrażliwe informacje, jeżeli użytkownik sam zdecyduje się je zapisać. SourceClip nie analizuje automatycznie historii przeglądania ani nie śledzi odwiedzanych stron w tle.

Gdzie dane są przechowywane?

Dane są przechowywane lokalnie przy użyciu API chrome.storage.local w profilu przeglądarki Chrome. W obecnej wersji rozszerzenie nie przesyła zapisanych danych do serwerów twórcy ani do zewnętrznych usług i nie prowadzi analityki ani profilowania.

Eksport i import danych

Użytkownik może samodzielnie zapisać kopię danych w pliku JSON lub Markdown albo wczytać własny plik. Wyeksportowany plik pozostaje w miejscu wybranym przez użytkownika i może zawierać treść notatek, tytuły i adresy stron. Za dalsze udostępnianie takiego pliku odpowiada użytkownik.

Uprawnienia

  • storage: lokalne przechowywanie fragmentów, projektów i preferencji.
  • contextMenus: zapisywanie tekstu zaznaczonego na stronie po wybraniu polecenia w menu kontekstowym.
  • sidePanel: wyświetlanie aplikacji w panelu bocznym Chrome.

Usuwanie danych

Użytkownik może usuwać pojedyncze fragmenty, projekty i wszystkie zapisane fragmenty z poziomu interfejsu rozszerzenia. Usunięcie danych z profilu Chrome lub odinstalowanie rozszerzenia może również spowodować utratę danych. Przed takimi operacjami warto zrobić eksport JSON.

Zmiany polityki

Jeżeli przyszłe wersje zmienią sposób przetwarzania danych, polityka zostanie odpowiednio zaktualizowana przed wprowadzeniem tych zmian.

SourceClip Privacy Policy

Last updated: November 6, 2026

Data processed

SourceClip allows people to save manually entered notes and selected text from websites. When a user invokes Save Selection, the extension may store the selected text, webpage title and URL, and the save date. It also stores project names, clip-to-project assignments, interface language, and theme settings.

Saved notes can contain personal or sensitive information if the user chooses to save such content. SourceClip does not continuously monitor browsing history or collect pages in the background.

Local storage and transfer

The data is stored locally in the user's Chrome profile using chrome.storage.local. The current version does not send saved data to the developer's servers or third-party services, and does not include analytics or user profiling.

Import and export

Users may export a backup as JSON or Markdown or import files of their own. Exported files may contain note text, page titles, and source URLs. Users control where these files are saved and whether they share them with others.

Permissions

  • storage: locally retain clips, projects, and preferences.
  • contextMenus: let users save their selected text on demand.
  • sidePanel: display SourceClip in the Chrome side panel.

Deleting data

The interface offers controls to delete individual clips, projects, or all saved clips. Removing the extension or deleting its Chrome profile data may also delete local data. Users should create a JSON backup before such actions.

Policy updates

This policy will be revised before any future version materially changes how user data is handled.
